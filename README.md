## 📌 About the Internship

The internship focused on building a practical foundation in modern front-end web development using **semantic HTML5, accessibility practices, responsive CSS architecture, asynchronous JavaScript, REST APIs, and full-stack project deployment**.

The programme followed a structured, task-based curriculum combining conceptual learning with hands-on project work. The final outcome was a live, publicly deployed portfolio website that hosts two additional working applications developed during the internship:

- A real-time Weather Dashboard using a public REST API
- A modular e-commerce-style product catalog

The internship was completed under industry mentorship through Thiranex Education LLP. The work covered the complete front-end development workflow, from semantic structure and responsive styling to API integration, client-side routing, state management, production build optimisation, and public deployment.

**Organization:** Thiranex Education LLP — an MSME-registered virtual internship and skill development organisation recognised under the Ministry of Micro, Small and Medium Enterprises, Government of India.

## 🏗️ System Architecture

The project was organised into the following layers:

| Layer | Responsibility |
|---|---|
| **Presentation Layer** | Semantic HTML5 templates for each view, styled with a mobile-first, token-driven CSS system |
| **Routing Layer** | Lightweight hash-based client-side router matching URL patterns and dynamic parameters without server-side rewrite rules |
| **Data Layer** | Static product catalogue module and a live REST API client using Fetch and async/await for city and weather data |
| **State Layer** | Publish/subscribe store managing cart state independently from the views that read and update it |
| **View Layer** | Separate modules for home, product detail, cart, and checkout screens, each owning its own DOM and event listeners |
| **Deployment Layer** | Static hosting through GitHub Pages or Netlify with a minified production build using Terser and clean-css |
